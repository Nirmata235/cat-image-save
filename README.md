## Программа Cat-image-save
## Программа: 
1. Запрашивает у пользователя текст для картинки и токен Яндекс.Диска.
2. Получает изображение кота с этим текстом через API cataas.com.
3. Создаёт на Яндекс.Диске папку с вашим названием.
4. Загружает изображение в эту папку.
5. Сохраняет в локальный файл `result.json` имя загруженного файла и его размер в байтах.

## Требования

- Python 3.8 или выше
- Библиотека `requests`

## Установка

1. Склонируйте репозиторий или скачайте его как ZIP:
  
   git clone https://github.com/ваш-username/cat-image-uploader.git
   cd cat-image-uploader
  
## Получение токена Яндекс.Диска

Токен нужен для доступа к вашему Яндекс.Диску через API. Получить его можно на странице [Полигон Яндекс.Диска](https://yandex.ru/dev/disk/poligon/):

## Запуск

python main.py
